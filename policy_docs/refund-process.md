# How Refunds Are Processed

## Timeline
Once a cancellation is confirmed, the refund is issued to the original payment
method. Card refunds typically settle in **5 to 10 business days** depending on
the issuing bank. A refund reference code (for example RF-48210) is generated
at the moment of cancellation and shown to the guest immediately.

## Refund reference code
Every confirmed cancellation produces a unique refund code in the format
`RF-` followed by five digits. Guests should keep this code; it is the fastest
way for support to locate the transaction.

## Partial refunds
When a rate plan only allows a partial refund (for example the Semi-Flexible
50% window, or the Flexible one-night penalty), the retained amount is shown as
the "non-refundable amount" on the quote. The guest is charged nothing extra;
the retained amount is simply not returned.

## Currency
Refunds are made in the same currency as the original booking. No currency
conversion fees are applied by the hotel.

## Disputes
If a refund has not appeared after 10 business days, the guest should contact
support with their booking reference and refund code so the payment can be
traced with the processor.
